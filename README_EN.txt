TerraLine GPS v0.9.9.60 – PATCHPUNK PUBLIC BETA (PC)
Mod for Farming Simulator 25 | Developer: PatchPunk

WHAT CAN TERRALINE GPS DO?
- A/B GPS guidance using two reference points (at least 20 m apart).
- Steering assistance along straight guidance lines up to 30 km/h;
  steering assistance is disabled above that speed.
- Create, save, load, and delete custom GPS courses shared by your farm.
- Manually shift the current guidance line, rotate it by 90 degrees,
  and adjust the working width.
- Implement offset diagnostics and customizable guidance-line appearance.
- Optional TerraLine GPS equipment for eligible vehicles in the standard
  vehicle shop: €0 without TerraLine (default) or +€10,000 with TerraLine.
- Install or change the equipment later in the standard FS25 workshop.
- Compact GPS status indicator to the left of the original GIANTS
  speedometer, with a dark, slightly transparent background.
  No indicator is shown on vehicles without TerraLine GPS equipment.

INSTALLATION
1. Back up your savegame.
2. Remove older TerraLine GPS ZIP files and any extracted TerraLine
   folders from your mods directory.
3. Copy this ZIP as-is into your FS25 mods folder. Do not extract it.
4. In multiplayer, use the same mod version on the dedicated server
   and all clients.

CONTROLS (can be reassigned in the FS25 controls menu)
Alt+T               : Toggle TerraLine GPS main power ON/OFF
Alt+B               : Set point A or point B
Alt+X               : Toggle GPS steering assistance ON/OFF
Alt+M               : Open/close the TerraLine menu
Alt+R               : Rotate the guidance line by 90 degrees
Alt+Page Up/Down    : Shift the GPS guidance line in 1 cm increments

IMPORTANT BETA INFORMATION
- TerraLine GPS equipment is purchased/configured and saved separately
  for each vehicle.
- The GPS main power switch always starts OFF, even if the vehicle has
  purchased TerraLine GPS equipment.
- GPS courses belong to the farm and are shared by its members.
  All farm members may create, save, and delete courses. The server
  checks the player's farm membership.
- Testing with one client on a dedicated server was successful,
  including saving, workshop configuration, and server restart.
  Two simultaneous players and player-hosted multiplayer are NOT YET
  confirmed. Please report bugs with steps to reproduce and log files.
- Experimental tramline management, field-edge tramlines, and section
  control are NOT included. A separate add-on is planned.
- Developer menu on page 4: its diagnostics PIN is only a UI gate,
  not secure access control. Developer diagnostics are OFF by default.
- gsGPSSteerTest is disabled in this public beta.
- No paid downloads. Not an official GIANTS product.
